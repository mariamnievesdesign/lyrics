# Letras

Ventanita flotante para Windows que muestra la letra sincronizada de la canción que está sonando, siempre por encima de todo.

- Detecta la música desde Windows (Chrome, Edge, Spotify, YouTube Music…).
- Busca la letra en [LRCLIB](https://lrclib.net), una base de datos libre.
- Estilo glass: desenfoca lo que hay detrás.

## Instalar

1. Ve a **Releases** y descarga el último `Letras.exe`.
2. Ábrelo. Si Windows muestra "Windows protegió su PC", haz clic en **Más información → Ejecutar de todas formas** (pasa porque la app no está firmada).

## Uso

- **Mover:** arrastra la ventana desde cualquier parte.
- **Redimensionar:** arrastra los bordes.
- **Controles** (aparecen al pasar el mouse):
  - `−` / `+`: corrige la sincronía en pasos de 0.5 s si la letra va adelantada o atrasada.
  - `A` / `A`: tamaño de la letra.
  - `✕`: cerrar.

La app recuerda la posición, el tamaño y los ajustes.
